# KinoLink by VOID

KinoLink позволяет смотреть кино бесплатно - прямо со страниц Кинопоиска, без подписок, без рекламы и без лишних вкладок. Нажимаешь кнопку «Смотреть» на странице фильма - и открывается лёгкий минималистичный плеер с выбором источника видео, списком просмотренного и несколькими темами оформления. Всё (пока что) крутится локально на твоём компьютере: пользовательский скрипт для браузера + маленький сервер-плеер без фреймворков и тяжёлых зависимостей.

## Установка

### Быстрая установка (одна команда)

```bash
curl -sSL https://raw.githubusercontent.com/Est-Void/KinoLink_by_VOID/main/install.sh | sh
```

Скрипт склонирует репозиторий в `~/KinoLink_by_VOID`, проверит `python3`/`git` и (при наличии systemd) включит автозапуск сервера. Переменные окружения: `KINOLINK_DIR`, `KINOLINK_NO_SERVICE=1`; флаги: `--dir <path>`, `--no-service`.

### Вручную

1. Клонируйте репозиторий:

```bash
git clone git@github.com:Est-Void/KinoLink_by_VOID.git
cd KinoLink_by_VOID
```

2. Установите userscript в браузере (**Tampermonkey / Violentmonkey / Greasemonkey**):
   - поставьте расширение, например [Tampermonkey](https://www.tampermonkey.net/)
   - установите скрипт по [этой ссылке](https://github.com/Est-Void/KinoLink_by_VOID/raw/main/userscript/kinolink.user.js) _(или скачайте `userscript/kinolink.user.js` из репозитория вручную)_
   - на страницах Кинопоиска появится кнопка «Смотреть»

3. Запустите сервер на этом устройстве:

```bash
python3 player/server.py
```

Сервер поднимется на `http://127.0.0.1:8080`. Если порт занят, он автоматически выберет первый свободный в диапазоне `8080–8129`; конкретный порт можно указать так:

```bash
python3 player/server.py --port 8088
```

Остановить сервер можно сочетанием `Ctrl+C`. Для автозапуска после входа в систему используйте установщик без `--no-service`.

### Плеер в локальной сети

Чтобы использовать один сервер с телефона, планшета или другого компьютера в домашней сети, на устройстве с сервером запустите:

```bash
python3 player/server.py --lan
```

Сервер выведет адрес вида `http://192.168.1.5:8080`. На другом устройстве установите userscript, подключитесь к тому же Wi‑Fi и при первом нажатии «Смотреть» введите этот адрес. Скрипт сохранит его для следующих запусков. Если оставить поле пустым, будет сохранён режим localhost и повторный запрос не появится, пока локальный сервер доступен. При установке через systemd используйте `./install.sh --lan` или `KINOLINK_LAN=1`.

Не включайте `--lan` в публичной или гостевой сети. Если телефон не видит сервер, сначала откройте в его браузере `http://LAN_IP:8080/api/status`: должна отобразиться информация в JSON. При проблеме проверьте, что устройства находятся в одной сети, отключена изоляция клиентов Wi‑Fi и фаервол ноутбука разрешает TCP-порт сервера.

4. Откройте страницу фильма на Кинопоиске (`kinopoisk.ru/film/...` или `kinopoisk.ru/series/...`) и нажми **«Смотреть»**.
